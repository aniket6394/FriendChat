# FriendChat 💬

A modern real-time chat application built with React, Node.js, Express, Socket.IO, and Cloudinary. FriendChat focuses on a smooth communication experience with real-time messaging, media sharing, and upcoming voice communication.

> 🚧 This project is currently under active development.

## Current Features

- 💬 Real-time messaging
- 😀 Emoji support
- 🎞️ GIF search & sharing
- 🖼️ Image sharing with Cloudinary
- ⌨️ Live typing indicator
- 👥 Room-based chat (up to 4 users)
- 👤 Avatar selection
- 👑 Host management
- 📜 Chat history for new users
- 🚪 Join & leave notifications
- 📋 One-click room ID copy
- 🎤 Real-time microphone status

## Upcoming Features

- 🔊 Real-time voice chat (WebRTC)
- 📁 File sharing
- 🎨 UI improvements
- ⚡ Better room management
- 🔒 Authentication
